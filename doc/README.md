# Aurora Borealis Core Documentation

This directory contains technical documentation inherited and developed across the Aurora Borealis Core codebase.

## Documentation Status

Aurora Borealis Core is derived from earlier open-source blockchain software. Some lower-level historical documents in this directory may retain upstream Bitcoin Core or Ravencoin Core terminology.

Those historical references must not be interpreted as authoritative Aurora Borealis mainnet parameters.

For current Aurora Borealis project information, use:

- the repository root README.md;
- ROADMAP.md;
- SECURITY.md;
- official releases;
- the official Aurora Borealis Coin Whitepaper when published.

## Building

Platform-specific build notes are available under doc/build-*.md.

Because some build documents originate upstream, executable names and Aurora Borealis-specific paths should be verified against the current source tree before old commands are used verbatim.

The generic source build begins with:

    ./autogen.sh
    ./configure
    make
