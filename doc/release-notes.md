## Upgrade

Shut down the existing Aurora Borealis Core instance cleanly before replacing
the binaries.

Primary executables are:

- `auroraborealisd`
- `auroraborealis-cli`
- `auroraborealis-qt`

Back up wallet data before performing software upgrades.

## Compatibility

Aurora Borealis Core is maintained for supported build environments documented
in the repository. Platform-specific binaries are published only when they have
been built and verified for the release.
