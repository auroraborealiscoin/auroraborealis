# Aurora Borealis Community Code of Conduct

Aurora Borealis Coin is an open-source technical project.

Project spaces should support constructive technical discussion, collaboration and responsible community participation.

Participants are expected to:

- communicate respectfully;
- discuss technical disagreements on their merits;
- avoid harassment, threats and personal attacks;
- avoid spam, impersonation and deceptive promotion;
- respect privacy and security;
- never request or publish another person's private keys, credentials or confidential information;
- distinguish verified project information from speculation;
- avoid presenting unofficial statements as official Aurora Borealis Coin announcements.

## Technical Collaboration

Code review, bug reports, testing and technical criticism are welcome when they are specific, reproducible and focused on improving the project.

Security vulnerabilities should be reported according to SECURITY.md rather than disclosed irresponsibly in public channels.

## Moderation

Project maintainers may moderate contributions or community activity that materially disrupts technical collaboration, creates security risks, impersonates official project channels or repeatedly violates these expectations.

## Scope

This code of conduct applies to official Aurora Borealis Coin repositories, documentation spaces and official community channels.
