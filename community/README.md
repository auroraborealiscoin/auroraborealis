# Aurora Borealis Coin Community

Aurora Borealis Coin is an open-source blockchain project.

Community participation can include:

- operating independent full nodes;
- GPU mining;
- operating independent mining pools;
- reviewing source code;
- testing releases;
- contributing documentation;
- developing monitoring and infrastructure tools;
- reporting bugs and security issues responsibly;
- improving wallet usability;
- developing independent explorers, wallets and services;
- translating project documentation.

## Community Safety

No legitimate Aurora Borealis Coin administrator, contributor or community member needs your private key or wallet seed.

Never disclose:

- private keys;
- wallet seed phrases;
- wallet passwords;
- RPC passwords;
- exchange credentials;
- server credentials.

## Independent Projects

Third-party wallets, pools, explorers, websites and other services should clearly identify themselves as independent unless they are operated by the official Aurora Borealis Coin project.
