# Aurora Borealis Coin Roadmap

This roadmap describes technical and project objectives. It does not promise market value, exchange listing, price performance or financial return.

## Phase 1 - Core Network

Status: **Complete**

- independent Aurora Borealis mainnet;
- ABRS network identity;
- KAWPOW mining;
- DGW-180 difficulty adjustment;
- 60-second target blocks;
- 900 ABRS initial block reward;
- 2,100,000-block halving interval;
- Core wallet and daemon;
- DNS bootstrap;
- fixed-seed fallback;
- public Core nodes.

## Phase 2 - Public Infrastructure

Status: **Complete / Pre-launch locked where applicable**

- official website;
- blockchain Explorer;
- mining Pool;
- Faucet;
- HTTPS/TLS;
- public network telemetry;
- release distribution.

Pool Stratum and production Faucet payouts remain intentionally locked until go-live.

## Phase 3 - Official Public Launch

Original target: **16 September 2026** — officially launched **1 September 2026**

- activate public Pool Stratum;
- verify controlled GPU miner connection;
- verify accepted KAWPOW share;
- fund production Faucet;
- activate Faucet payout pipeline through controlled safety gates;
- perform first controlled production claim;
- create post-launch infrastructure certification.

## Phase 4 - Documentation and Community

- publish official ABRS Whitepaper;
- maintain technical documentation;
- establish official social channels;
- establish community support channels;
- publish mining and wallet guides;
- encourage independent nodes and miners.

## Phase 5 - Ecosystem Growth

Potential future work may include:

- additional wallet and platform packaging;
- third-party mining pools;
- independent explorers;
- hardware and software wallet integrations;
- developer tooling;
- monitoring and operational improvements;
- external project-directory and data-service submissions.

Future features remain subject to technical review, security analysis and community development.
